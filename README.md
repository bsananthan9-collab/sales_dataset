# Sales Dataset Analysis

## Project Overview

This project analyzes a sales dataset using Python and Jupyter Notebook. The dataset contains order details, product information, regional sales data, quantities sold, and total revenue.

## Files Included

* **sales_dataset(1).ipynb** – Jupyter Notebook containing data analysis and visualization.
* **sales_dataset og(1).csv** – Original sales dataset.

## Dataset Information

The dataset contains **125 records** and **8 columns**:

| Column Name | Description             |
| ----------- | ----------------------- |
| OrderID     | Unique order identifier |
| OrderDate   | Date of the order       |
| Region      | Sales region            |
| Product     | Product sold            |
| SalesPerson | Sales representative    |
| Quantity    | Quantity sold           |
| UnitPrice   | Price per unit          |
| TotalAmount | Total sales amount      |

## Technologies Used

* Python
* Pandas
* Jupyter Notebook
* Matplotlib / Seaborn (if used in the notebook)

## Objectives

* Load and explore sales data
* Perform data cleaning and preprocessing
* Analyze sales performance
* Identify regional and product-wise trends
* Create visualizations for better insights

## How to Run

1. Open the Jupyter Notebook:

   ```bash
   jupyter notebook
   ```
2. Open `sales_dataset(1).ipynb`.
3. Run the cells sequentially to reproduce the analysis.
